# 国科大生存指南（个人版）

此仓库创建自中国科学院大学2024级生物科学专业本科生层析液，主要作为个人学习途中的记录，或许也可作为他人的参考。文字如非额外声明均为本人原创，使用ChatGPT对格式和措辞进行微调。

如果你有类似的、想要补充的经历（比如物理专业的科研经验、计系研讨课生存心得、或者若干年后被更新的政策等等，任何本人因为个人经历有限而无法提供的其他心得），欢迎提交issue，我会做成友情链接贴上去，可以是另一个完整的经验分享仓库，也可以是仅针对很小一个方面的心得。

仓库创建于2026.8.17，刚刚提交完访学的申请，就最近的经历做一些总结。

2026.10.12更新：新增大一秋季-科研相关内容。

本页面更新可能不及时。也可能因为我push错了而出现一些写到一半或者格式错误的东西。
